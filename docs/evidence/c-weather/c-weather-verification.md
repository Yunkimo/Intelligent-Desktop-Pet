## 3. 人工验收步骤（开发者工具 + 真机）

1. 首页出现「明日带伞提示」卡片：城市（默认长沙）、目标日期、更新时间；雨/无降水/暂不可用三种形态，未知时可点「重试」。
2. 点城市 → 常用城市快捷选择或输入任意城市 → 保存；切账号后城市偏好各自独立；已有订阅时切换城市会提示原订阅仍绑定原城市。
3. 点「订阅带伞提醒」→ 微信授权弹窗（模板为 B 配置的天气模板）→ 同意后卡片显示「已授权，今晚判断天气」；拒绝/关闭分别有对应状态与提示，不自动反复弹窗。
4. 取消订阅 → 「已取消」；发送中取消被后端 409 拒绝并提示。
5. **真机实收**（与 B 联调，21:00 前完成订阅）：有雨场景下关闭小程序与桌宠，21:00 后微信服务通知收到一条「明日带伞提醒」；点击消息进入小程序天气详情页，显示城市/日期/状态/发送时间；重复调度不多发；另一账号无法打开该详情（404）。
6. 记录实测发送时刻、接收时刻与 event_id，作为实收证据。

## 4. 边界与说明

- 一次性授权只针对本次事件：页面文案明确「仅明天有降水时发送、每次订阅仅本次有效」，不承诺每天自动推送。
- 前端申报 accept 不等于微信已接受：状态一律以服务端返回为准；发送结果不明的登记用同一 request_id 幂等恢复，不换 ID 盲目重建事件。
- 订阅事件在用户点击前于后台准备（保证点击时同步调用授权，避免手势上下文丢失）。
- 城市偏好为小程序本地按账号保存，暂无跨端同步（任务书允许）。
- 天气接口响应不表示消息已发送；上游英文描述不编造雨量与时段。
