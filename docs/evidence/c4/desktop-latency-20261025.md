# C4 到期 5 秒内展示实测（2026-10-25）

结论：本次 5/5 条专用 PC 提醒通过。计入服务器与电脑时钟差的不确定性后，最慢一条的延迟上界为 **2.069 秒**，均在到期后 5 秒以内。这是当前网络、单客户端及本轮 5 个样本的结果，不代表所有负载和网络条件下的时延保证。

服务器仍是已核对的 d418655，本次只由用户将 SCHEDULER_INTERVAL_SECONDS 从 30 改为 1 并重启，MainPID=65574、active/running；见 [配置与重启](latency-server-interval.json)。未部署本机合入 develop 的代码。测试走 http://8.148.29.9:8080 和 ws，不能替代正式 HTTPS/WSS 验收。

使用本机 C4 合入 develop 9bca38f 的桌宠业务代码，运行 [云端 GUI 计时脚本](../../../scripts/check_cloud_reminder_latency.py)。脚本复用原验收的真实 WsListener → PetWindow → REST 正文校正 → 气泡 Paint 后回调，实际 Windows 平台，逐条确认气泡可见并保存仅含测试气泡的截图。未替换后端调度或客户端提醒业务。5 次到期间距 8.37 秒，避免提示覆盖，并采样不同扫描相位。语音关闭，仅验证展示时延；前一轮语音验收记录另存。
