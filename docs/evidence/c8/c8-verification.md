## 3. 尚未执行的人工验收（待成员 C 在开发者工具与手机上完成）

1. 日程页点「＋」→ 出现「一句话创建日程」输入框；点「手动添加」仍可走原表单（回退路径）。
2. 输入「明天下午三点提醒我交实验报告；下周五前交报告」→ 点「解析」→ 出现 2 张确认卡：第一张带提醒时间（明天 15:00）、第二张只有截止日期（下周五）；截止项无提醒时间。
3. 缺项/过去时间：输入「交实验报告」（标「日期不明」）、「昨天提醒我交报告」（标「时间已过去」）→ 卡片标黄提示，可编辑/移除后再保存。
4. 点「确认保存」→ 列表出现新日程；带提醒的日程在列表里有「订阅提醒」按钮，订阅状态以服务端为准（未订阅/待授权等）。
5. 多事项可选择：移除其中一张卡片后只保存剩余项。
6. 连点「解析」/「确认保存」不重复；解析失败保留原文可改后重试；保存失败保留草稿可修正重试。
7. 真机预览同第 2、4 步（微信实收属 C3 范畴，本次仅验证客户端流程）。

## 4. 边界与说明

- 解析只返回草稿，不落库、不触发微信授权；确认保存仅调 POST /api/tasks，不额外 POST PC 提醒（B5 后端原子联动）。
- 相对日期按客户端当前时间（带偏移）与 Asia/Shanghai 解释；跨时区设备暂以该约定为准。
- 已经出站的微信消息不能撤回：改期/删除后的提示与 C3 既有行为一致。
- 复杂连接句（然后/另外/并且且单段）依赖后端可选 LLM_TEXT_MODEL；未配置时按规则拆分，错误码 502/504/429 与 B7 契约一致。
