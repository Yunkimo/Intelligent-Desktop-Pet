# 天气预报兼容修复和实测记录

2026-11-04，基于 develop 6c68f21，修复分支 fix/weather-tip-codes。

## 原因和修复

wttr.in 的实际逐时预报出现 125 Haze、146 Smoke、149 Smoky haze、152 Smog。
原白名单不包含这些代码，导致任意小时含上述天气时，整个次日预报返回 unknown。
将四种非降水天气纳入 dry_codes，继续拒绝未识别代码，不用缺失数据冒充晴天。
