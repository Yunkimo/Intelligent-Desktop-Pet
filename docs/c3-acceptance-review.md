## 5. 验收期间的缺陷闭环（均有提交与回归）

| 缺陷 | 修复 | 回归 |
|---|---|---|
| 授权弹窗在真机上被静默吞掉（网络请求先于弹窗） | 弹窗改为同步触发 | 真机复验通过 |
| 真机 toast 被 loading 遮罩盖住 | 先 hideLoading 再 toast | 真机复验通过 |
| 401 会话失效死错误 | 自动重登 + 幂等重试 | 自动化用例覆盖 |
| 重复点击重复弹框/登记 | 本地防抖 + 409 友好化 | 自动化用例覆盖 |
| AppID 与模板账号不匹配（code2Session 40125） | 修正 AppID | 微信 40029 验证通过 |
| 删除任务残留孤儿提醒 | 删除时级联清理 | 真机复验通过 |
| 编辑任务后无法重新订阅 | 清除本地标记 + 提醒同步更新 | 自动化用例覆盖 |
