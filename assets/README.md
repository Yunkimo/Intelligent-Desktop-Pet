# 宠物素材约定

把你的宠物图片（透明 PNG 效果最好）放进本目录，然后在根目录 `config.json` 的 `frames` 里列出文件名：

```json
{
  "frames": ["idle_0.png", "idle_1.png"],
  "sprite_size": 180
}
```

约定：

- **格式**：透明背景 PNG（推荐）或 JPG。
- **尺寸**：正方形效果最好；程序会按 `sprite_size` 等比缩放。
- **帧动画**：`frames` 里放多张图即循环播放（可用于眨眼/空闲动画）；只放一张则静态显示。
- **占位**：`frames` 为空（`[]`）时，程序会自动画一只占位小猫，方便先跑起来。
